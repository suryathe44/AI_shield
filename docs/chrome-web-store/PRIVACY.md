# AI Shield Chrome Extension Privacy Policy

Effective date: September 13, 2026

This policy applies to the AI Shield Chrome extension, version 1.0.0. The separate AI Shield website and API have different workflows and are not used by this extension.

## Content processed locally

Only when you click a scan button, the extension analyzes the message you paste, the text you select, or the current webpage URL and rendered main-frame body text. Scans are limited to 20,000 characters. Page text may contain personal information visible on that page. The extension uses this content solely to compute and display scam indicators, a risk score, explanations, and recommendations on your device.

## No collection, transmission, or retention

The extension does not send analyzed content, browsing activity, personal information, or results to the developer or any third party. It does not use analytics, advertising, remote model services, or the AI Shield API. Network connections from the extension are blocked by its content security policy. Content and results remain in popup memory only; closing the popup clears them. There is no scan history, account, or cloud storage. Chrome and the Chrome Web Store operate under Google's own policies.

## Permissions

- **activeTab:** temporary access to the active tab after you invoke the extension, so an explicit scan can read selected text or rendered page text and its URL.
- **scripting:** execute the text-capture function in the active tab for that scan.

There is no persistent all-sites access and no background monitoring. The extension does not access cookies, saved passwords, browser history databases, or form-field values through dedicated APIs. Sensitive information displayed as normal page text can be included when you choose to scan that page.

## Your choices

Use pasted-message analysis to choose precisely what is inspected. Scan buttons authorize only that scan. Clear removes the popup's message and result; close the popup to discard all transient content. Remove the extension through Chrome's extension settings at any time.

## Contact and changes

Questions and privacy concerns can be raised at https://github.com/suryathe44/AI_shield/issues. Do not include private messages, passwords, or other sensitive content in public issues. Any future change to these practices will be reflected in this policy and the extension's disclosures.

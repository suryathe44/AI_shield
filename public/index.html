                          Architecture

                          How AI Shield makes its decisions

                          1. Multi-layer detection

                          AI Shield combines local machine-learning classification using Naive Bayes, rule-based indicators, and behavioral analysis to identify phishing, impersonation, coercion, and scam patterns.

                          2. Minimal encrypted logging

                          Logging is optional. When enabled for an API request, AI Shield stores encrypted audit metadata, hashed identifiers, and a content preview only if separately selected.

                          3. Explainable decisions

                          Each completed verdict shows detected signals, suspicious patterns, and recommended actions so users can understand the score.

                          4. Ready for extension

                          The modular detection and API layers can support future browser extensions, OCR improvements, voice-scam detection, and mobile workflows.
